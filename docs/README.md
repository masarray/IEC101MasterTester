# IEC101 Master Tester Landing Page

Static GitHub Pages site for `IEC101MasterTester`.

Files:

- `index.html` - landing page
- `styles.css` - visual system
- `script.js` - reveal animation and small interactions
- `assets/` - product icon/profile assets

The page intentionally states that the native IEC-101 stack is experimental and that `lib60870.NET` remains the current production baseline until the migration gates pass.
