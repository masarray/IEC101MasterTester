Built for practical engineering

One workspace for values, events, commands, and protocol truth.

IEC101 Master Tester is designed for bench testing and commissioning preparation where engineers need to know not only that a value changed, but which frame, cause, class, quality, and response path produced it.

FAQ

Answers before you connect to a device.

Can this be used for professional FAT/SAT?

Yes, as an engineering support tool. Use it with an approved test procedure, safe isolation boundary, and project acceptance criteria.

Does it need installation?

No. Download the Windows portable ZIP from GitHub Releases, extract it, and run the application on a compatible Windows machine.

Why is the link responsive but values are empty?

The link layer may be alive while the application image is not ready. Check General Interrogation, Class 1 polling, and returned ASDU data in the Line Monitor.

Can I build it myself?

Yes. Build from source on Windows using Visual Studio or MSBuild. The main application does not require package restore.
