# Professional Use

IEC101 Master Tester is intended to support professional engineering work such as FAT, SAT preparation, commissioning checks, troubleshooting, and SCADA/gateway verification.

## Recommended use cases

- FAT evidence capture for IEC-101 serial links.
- RTU or gateway troubleshooting.
- Verification of Class 1/Class 2 polling behavior.
- General Interrogation observation.
- Command confirmation and feedback verification.
- NUC active/standby redundancy testing.
- SOE replay and event-buffer review.
- Long-session communication availability observation.

## Use boundaries

The tool helps engineers observe, test, and document protocol behavior. It is not a certified protection, control, or safety system.

Before use on real equipment:

- obtain site authorization;
- isolate the test boundary;
- confirm command risk;
- agree the test procedure;
- define acceptance criteria;
- record the device configuration and communication profile;
- preserve raw evidence when reporting findings.

## Evidence handling

Good evidence usually includes:

- screenshot of the session overview;
- Value Viewer snapshot;
- Event Log rows;
- Line Monitor extract;
- serial profile;
- link address and CASDU;
- test step and expected result;
- observed result and timestamp.

For formal FAT/SAT submission, pair tool evidence with approved project forms and sign-off records.
