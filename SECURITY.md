# Security Policy

IEC101 Master Tester is an engineering test tool for IEC-60870-5-101 serial communication workflows.

## Supported Versions

Security and stability fixes should target the current `main` branch unless a formal release branch is created.

## Reporting Issues

Please report security-sensitive issues privately to the maintainer before opening public issues.

## Field Use Disclaimer

Do not use this tool to operate production equipment without an approved test plan, isolation boundary, and site authorization. Validate command behavior in simulator/bench mode before connecting to real controlled stations.
