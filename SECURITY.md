# Security Policy

IEC101 Master Tester is an engineering test tool for IEC 60870-5-101 serial communication workflows.

## Supported version

Security and stability fixes target the current `main` branch and the latest published release package.

## Reporting issues

Please report security-sensitive issues privately to the maintainer before opening public issues.

## Field-use warning

Do not use this tool to operate production equipment without an approved test plan, isolation boundary, and site authorization. Validate command behavior in simulator or bench mode before connecting to real controlled stations.
